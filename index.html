Alpha VPS Backup

A personal utility for backing up files from a privately managed virtual server to the owner's Google Drive account using Rclone.

Google Drive access

The utility uses the drive.file OAuth scope to create and manage backup files authorized for this application. It is intended for the owner's personal use, not as a public backup service.
