Privacy policy

Effective November 17, 2026.

Alpha VPS Backup is a personal backup utility. Google OAuth is used to authorize access to backup files under the drive.file scope. OAuth credentials are stored on the owner's server and used to authenticate backup operations.

Google Drive data is used only to upload, retrieve, list and verify authorized backups. The utility does not sell Google user data, use it for advertising, or provide it to third parties for their own purposes. Google and the hosting provider process data as necessary to provide their services.

The owner controls backup retention and can delete backup files in Drive or revoke access through Google Account settings. Revocation stops authorized access but does not automatically delete existing backups.

Google API data use adheres to the Google API Services User Data Policy, including Limited Use requirements.

For privacy questions, use the contact link below. Do not post credentials or private data in public issues.
